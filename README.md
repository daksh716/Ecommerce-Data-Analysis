# 📊 Ecommerce Data Analysis

## 📌 Project Overview

This project focuses on analyzing **E-commerce sales data using Python and Data Analytics techniques**.

The main goal of this project is to explore the dataset, clean and analyze the data, identify important patterns, and generate meaningful business insights related to **sales, profit, customers, products, categories, regions, discounts, and orders**.

---

## 🎯 Project Objectives

* Understand and explore the E-commerce dataset
* Perform data cleaning and preprocessing
* Analyze sales and profit
* Identify top-performing products and categories
* Analyze customer segments and purchasing behavior
* Compare sales and profit across different regions
* Study the relationship between discount and profit
* Identify important trends and patterns
* Create meaningful data visualizations
* Generate actionable business insights

## 📁 Dataset

The project uses an E-commerce sales dataset containing information about orders, customers, products, sales, quantity, discounts, and profit.

### Important Columns

| Column        | Description                     |
| ------------- | ------------------------------- |
| Row ID        | Unique row identifier           |
| Order ID      | Unique order identifier         |
| Order Date    | Date when the order was placed  |
| Ship Date     | Date when the order was shipped |
| Ship Mode     | Shipping method                 |
| Customer ID   | Unique customer identifier      |
| Customer Name | Customer name                   |
| Segment       | Customer segment                |
| Country       | Country of the customer         |
| City          | Customer city                   |
| Postal Code   | Postal code                     |
| Region        | Sales region                    |
| Product ID    | Unique product identifier       |
| Category      | Product category                |
| Sub-Category  | Product sub-category            |
| Product Name  | Name of the product             |
| Sales         | Sales amount                    |
| Quantity      | Quantity ordered                |
| Discount      | Discount given                  |
| Profit        | Profit generated                |
